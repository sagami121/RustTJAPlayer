# TJAPlayer-S 拡張機能マニュアル

本ファイルでは、今回追加されたTJAパーサーの拡張機能（動的スクロール制御、マクロ機能、条件分岐命令）の使い方を説明します。

---

## 1. 動的スクロール速度制御: #SCROLL_EXPR

`#SCROLL_EXPR` 命令を使用すると、演奏中にスクロール速度を数式として動的に計算・適用できます。式評価エンジンが組み込まれているため、変数や数学関数を使用可能です。

### 基本構文
```tja
#SCROLL_EXPR: [式]
```

### 使用例
```tja
// 現在のコンボ数に応じてスクロール速度を変化させる
#SCROLL_EXPR: 1.0 + (<lc:combo> / 500)

// sin関数を使ってスクロールを揺らす（※sin関数は実装済み）
#SCROLL_EXPR: 1.0 + <math:sin>(<song:duration> * 0.1)
```

---

## 2. マクロ機能: #MACRO_START, #MACRO_END, #MACRO_CALL

頻繁に使用する譜面パターンや命令のセットを定義し、再利用することができます。

### 基本構文
```tja
#MACRO_START [マクロ名]
... 譜面データや命令 ...
#MACRO_END

#MACRO_CALL [マクロ名]
```

---

## 3. 条件分岐命令: #IF, #ELSE, #ENDIF

式の結果に基づいて、譜面の特定の箇所を読み込むかどうかを動的に切り替えます。

### 基本構文
```tja
#IF [式]
... [式] が真(0以外)の場合に読み込まれる譜面 ...
#ELSE
... [式] が偽(0)の場合に読み込まれる譜面 ...
#ENDIF
```

### 使用例
```tja
// 難易度(cd)が8より大きい場合のみ、高難易度用の配置を読み込む
#IF <cd> > 8
1111,
#ELSE
1010,
#ENDIF
```

---

## 4. 設定ファイル (config.ini)
譜面制作モードの表示設定は `config.ini` で変更可能です。`true`/`false` または `T`/`F` (大文字小文字問わず) を指定できます。

```ini
// 譜面制作モードの表示設定
CreationMode_ShowMeasure=true  // 小節数を表示する (T でも可)
CreationMode_ShowMeasure=false // 小節数を非表示にする (F でも可)
```
